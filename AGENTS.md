# Работа над проектом

Это небольшой учебный сервис: Python 3.11+, FastAPI, SQLite из стандартной библиотеки,
Jinja2 и HTML/CSS. Интерфейс и документация — на русском, имена в Python — на английском.

- Прочитай README и код, относящийся к задаче. Уточняй неоднозначные требования.
- Сохраняй минимальный стек и запуск `python -m app --demo`. Node.js, Docker, ORM,
  внешние сервисы и GitHub Actions для этого проекта не нужны.
- Не реализуй дополнительные функции без соответствующего запроса.
- Общая валидация находится в `app/models.py`, SQL и атомарные изменения — в
  `app/repository.py`. HTML и API должны использовать одни и те же правила.
- Параметризуй значения в SQL. Не отключай экранирование пользовательского текста в Jinja2.
- Не допускай двойного занятия слота и пересекающихся записей пациента. Проверки и
  изменение данных должны выполняться в одной транзакции.
- Даты и время хранятся в UTC, отображаются в фиксированном UTC+3 (МСК).
- Существующие данные должны сохраняться. Изменение `CREATE TABLE` не обновляет
  старую базу: при изменении схемы обеспечь и проверь переход с предыдущей версии.
- Демонстрационное наполнение не должно изменять непустую базу.
- При изменении поведения добавляй осмысленные тесты, включая ошибочный ввод.
- Перед завершением выполни в виртуальном окружении `python -m pytest`,
  `python -m ruff check .` и `python -m ruff format --check .`.
- Не включай базы, окружения, кэши, ключи и реальные персональные данные в коммиты.
